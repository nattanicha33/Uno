# Color Clash Party 🎴

โปรเจกต์เกมการ์ดสำหรับงานเว็บแอป/เกมของนักเรียน  
ออกแบบจากแนวคิดเกมการ์ดเปลี่ยนสีในภาพตัวอย่าง แต่ใช้ชื่อ โลโก้ และกราฟิกที่สร้างใหม่เพื่อให้เป็นผลงานของเราเอง

## โครงสร้าง
- `index.html` — โครงสร้างหน้าเมนู วิธีเล่น และหน้าเกม
- `style.css` — สี ธีม การ์ด responsive และเอฟเฟกต์
- `game.js` — ระบบสำรับ การแจกไพ่ กติกา BOT การเลือกสี การจั่ว และคะแนน
- `manifest.json` — ข้อมูลสำหรับติดตั้งเป็นเว็บแอป
- `sw.js` — Service Worker สำหรับ cache ไฟล์หลัก
- `README.md` — คำอธิบายโครงสร้าง

## วิธีเล่น
1. เปิด `index.html`
2. กดเริ่มเกม
3. ใส่ชื่อผู้เล่น
4. ลงการ์ดที่มีสีหรือเลข/สัญลักษณ์ตรงกับการ์ดกลาง
5. ถ้าลงไม่ได้ให้กดจั่ว
6. ใช้ Wild เพื่อเลือกสีใหม่
7. เมื่อเหลือ 1 ใบ กด UNO!
8. คนที่หมดมือก่อนชนะรอบ

## จุดที่ตรงกับโจทย์
- เล่นได้จริงบนคอมพิวเตอร์และมือถือ
- มีเมนู / วิธีเล่น / ตั้งชื่อผู้เล่น / ระบบเกม
- มี BOT 3 คน
- มีการ์ดตัวเลข + การ์ดพิเศษ + Wild
- มีคะแนนและการเล่นรอบใหม่
- แยก HTML / CSS / JavaScript / Manifest / Service Worker มากกว่า Singlefile HTML
- สามารถอัปโหลดทั้งโฟลเดอร์ขึ้น GitHub Pages เพื่อให้ครูเปิดดูโครงสร้างได้

## วิธีนำขึ้น GitHub Pages
สร้าง repository ใหม่ แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ จากนั้นไปที่
Settings → Pages → Deploy from a branch → เลือก `main` และ `/root` → Save

หมายเหตุ: เกมนี้เป็นเกมการ์ดแนวเดียวกับภาพอ้างอิง ไม่ใช้โลโก้หรือไฟล์กราฟิกทางการของเกมต้นฉบับ
